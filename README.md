# Pizza-Sales-Report
# Project Overview
Data  Analysis of Pizza Sales to uncover customer purchasing patterns, sales trends and product performance. The dashboard enables stakeholders to monitor key business metrics and make data driven decisions using interactive filters by pizza category and date.
# Business problem
Pizza businesses need to understand sales performance, customer ordering behavior and product popularity to maximize revenue and improve operational efficiency. This dashboard answers key questions such as;
Which pizza category generate the most revenue?
Which pizza sizes are most popular?
What are the daily order trends?
Which pizzas are the best and worst performing?

Dataset
The analysis is based on pizza sales dataset containing order details, product information, order dates, pizza sizes, categories, quantities sold, and revenue.
Tools used
Power BI, Power query, SQL, Microsoft excel and DAX

Dashboard KPIs
Total Revenue, Average order value, Total orders, Total pizzas sold, Average pizzas per order, Daily trend for Total Orders, Sales percentage by pizza category and by pizza size, Total pizzas sold by Category, Top performing pizzas and worst performing pizzas.
Interactive features
Pizza category slicer, Date slicer.

# Key insights
Identified the highest and lowest performing pizzas based on sales and revenue.
Analyzed customer purchasing patterns through average order value and pizzas per order.
Evaluated daily order trends to identify peak sales periods.
Compared the contribution of each pizza category and size to total sales.
Highlighted product performance to support menu optimization and inventory planning.
